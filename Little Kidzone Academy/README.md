# Little Kidzone Academy website

This is the first static version of the Little Kidzone Academy website. It uses plain HTML, CSS and vanilla JavaScript so it can be opened without a build tool.

## Project structure

- `index.html` — page content and accessible semantic structure
- `styles.css` — responsive layout, colours and visual styling
- `script.js` — mobile navigation and current footer year
- `assets/images/` — place the official logo and approved photographs here

## Preview locally

Open `index.html` directly in a browser, or run a local server from this folder:

```text
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The logo was not present in the workspace when this version was created. The temporary `LK` mark should be replaced with the official logo in the next step.
